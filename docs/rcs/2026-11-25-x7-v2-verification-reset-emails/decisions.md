# X7 V2 Email Verification + Password Reset (BL x7casino.com / WL x7casino.io): decisions

Date: 2026-11-25 · Branch: `staging` · Commit: not yet committed · Migration: none (static email files only, no app or DB changes)

## Context
- The back-office (the sending platform, not CIO) needs two system emails for X7 Casino on the V2 design: **Email Verification** (registration) and **Password Reset**, in EN/FR/DE/IT/ES.
- **Domains:**
  - **BL** = `x7casino.com`. DE is the exception: `x7casino2.com`.
  - **WL** = `x7casino.io`, DE included.
  - BL and WL have different footers, set in the 2026-11-24 footer ticket.
- **Pattern:** one file per language. It holds both footers behind a domain conditional, like the approved Stakes verification email (`*|IF:DOMAIN_URL=stakescasino.com|*` … `*|ELSE:|*` … `*|END:IF|*` around `<body>`).
- **Merge tags:** the platform's, not CIO liquid:
  - `*|PLAYER_FNAME|*`
  - `*|REGISTRATION_COMPLETEREGURL_TOKEN|*` (verification)
  - `*|RECOVER_URL|*` (reset)
- **Output:** `Approved Emails/X7 Casino V2/Verification and Reset/`
  - `x7v2-verification-email-{LANG}.html`
  - `x7v2-reset-password-{LANG}.html`

## Decisions

### 1. Built from the live MailCraft export, not the Approved Emails V2 file
- **Decision:** each version is rendered through MailCraft's real export path: `renderTemplate`, then `buildSectionTransformer` with `darkModeLock: true`. The inputs are the BL / WL master HTML and the master configs in `prisma/templates/x7v2.ts` and `x7v2Whitelist.ts`.
- **Why:** the master templates carry fixes that the approved V2 file does not have:
  - the Gmail iOS dark-mode lock
  - the GamCare footer
  - the WL Boni Tech license
  - the WL address auto-link fix
  - the BL payment-row and license removal
- Rendering through the same code keeps these emails byte-consistent with campaign exports.
- **Sections removed:** THUMBNAILS, USERNAME_PASSWORD and TERMS, through the same `deleteSection` used for saved templates. The red divider above the footer stays.

### 2. Conditional: `*|IF:DOMAIN_URL=x7casino.io|*` → WL, ELSE → BL (D1)
- **Decision:** WL goes in the IF and BL in the ELSE, in all 5 languages.
- **Why:** a single rule needs no DE special case, because `x7casino2.com` falls to BL on its own. It also matches Stakes, where the secondary domain is the IF and the main brand is the ELSE.
- **Structure:** one shared `<head>`, then IF → WL `<body>` → ELSE → BL `<body>` → END:IF. The generator aborts if the BL and WL heads are not byte-identical.
- **Assumption:** `DOMAIN_URL` is the bare host (`x7casino.io`, no `www.` or scheme), as in the Stakes email. If the platform sends something else, every player gets the BL version.

### 3. Unsubscribe line removed (D2, revised)
- **First decision:** keep it. **Revised by the user:** remove it.
- **Why:** these emails are not sent through CIO, so `{% unsubscribe_url %}` does not apply. They are also transactional; the V1 X7 / Stakes verification and reset emails have no unsubscribe either.

### 4. Banners (D3)
- **Verification:** the user-supplied `https://userimg-assets.customeriomail.com/images/client-env-110039/01M89HB10SNHJW2JZ24RY23MKG.jpg`, one image for all 5 languages. It replaced the V1 per-language `{LANG}- Main.png` placeholder on 2026-11-25.
- **Reset:** the user-supplied `https://userimg-assets.customeriomail.com/images/client-env-110039/01M88TGFGN9T7YV5G5VQMEY2TC.jpg`, one image for all 5 languages.

### 5. Copy and links
- **Headline:** keeps the V2 Bebas uppercase style, for example `Hello, *|PLAYER_FNAME|*!` (FR `Bonjour`, DE `Hallo`, IT `Ciao`, ES `¡Hola`). The player name therefore shows in capitals, the same as V2 campaigns.
- **Body:** one paragraph with `<br><br>` breaks, rendered by `paragraphRenderer`, so it is styled and dark-mode-locked like campaign bodies. Verification bolds **X7 Casino** (IT: **Casinò X7**).
- **ES copy (D4):** used exactly as provided, including the `¡ … !` that spans two sentences.
- **FR:** a non-breaking space goes before every `!`, `?` and `:` (headline, body and notes) so a mark never wraps onto its own line.
- **After the CTA:**
  - Verification: a grey 14px Manrope expiry note.
  - Reset: the fallback block. It is grey text, then `*|RECOVER_URL|*` as a red (#c80824) bold link with `word-break: break-all`, then the grey "Wasn't you?" line.
- **Links:**
  - The logo, banner and CTA all link to the token URL, as in V1.
  - The footer 18+ and Responsible Gambling links come from the master config per language: BL `x7casino.com/{lang}` (DE `x7casino2.com/de`), WL `x7casino.io/{lang}`. GamCare is on both.
- **`<title>`:** "X7 Casino — Verify Your Email" / "X7 Casino — Reset Your Password", in English in every language, as in V1.

### 6. Generated by script, verified by asserts
- **Generator:** `gen-sysmail.ts` (session scratchpad, not in the repo). It runs with `REDIS_URL=redis://127.0.0.1:1`, which makes the Redis cache miss quickly and fall back to disk, so no DB or Redis is needed.
- **Per-file asserts, all PASS for the 10 files:**
  - no `{{` or `{%` left
  - IF/ELSE/END each appear exactly once, in order
  - `*|PLAYER_FNAME|*` appears once per version
  - token counts are right (3 in verification, 5 in reset)
  - THUMB, username and unsubscribe are gone
  - the dark-mode lock is present
  - GamCare is present
  - every `href` belongs to its own version's domain
  - WL has the payment row and the Boni Tech license; BL has neither
